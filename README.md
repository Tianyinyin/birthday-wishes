# 魏老师的生日祝福

[打开生日动画](https://tianyinyin.github.io/birthday-wishes/)

温馨小屋里的 Q 版生日祝福，结尾显示「祝魏老师生日快乐，永远十八岁！」。

结尾采用绘本贺卡：奶油白手写祝福、粉色丝带、暖白灯串、柔和的木桌与花瓶质感，配少量动态光点和爱心。竖屏、近方形、横屏分别选择完整构图，祝福、帽子与双脚均不裁切。

点击屏幕六次，依次准备蛋糕、蜡烛、生日帽和鲜花，再关灯、点燃蜡烛。生日歌结束后，点击“开启麦克风吹蜡烛”并允许权限；按提示安静等待校准，再靠近手机麦克风轻轻吹气。也可使用“点击吹灭”。吹灭后升烟、飘出爱心、逐渐开灯，约半秒后开始渐显完整生日贺卡。

声音只在本机分析，不录音、不上传。结束或切到后台时停止收音。真实吹气灵敏度及微信、iPhone、Android 兼容性仍需真机确认；无法使用麦克风时，可点击吹灭，或尝试在系统浏览器打开。

仓库中的两个 HTML 内容一致：

- `index.html`：默认首页，直接打开网站网址即可播放。
- `birthday-wechat.html`：保留原来的文件名和访问链接。

图片、样式、动画和合成音频全部内嵌 HTML，无需另传素材文件夹或安装依赖。更新动画时，同时更新两个 HTML 文件，保持内容一致。

GitHub Pages 使用 `main` 分支的 `/ (root)` 发布。将上方“打开生日动画”的完整 HTTPS 链接通过微信发给老师即可。
